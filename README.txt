LEAD — THE NOBLE 100 | Frontend starter

FILES
- index.html: single-page website structure and content
- styles.css: responsive design and visual styling
- script.js: mobile navigation and dynamic copyright year
- assets/lead-lab-logo.png: provided Lead Lab logo

HOW TO RUN
1. Keep the index.html, styles.css, script.js and assets folder together.
2. Open index.html in a browser, or use VS Code with the Live Server extension.

BEFORE PUBLISHING
- Replace YOUR_EMAIL@example.com with the official contact email.
- Replace YOURNUMBER in the WhatsApp link with the business number including country code (digits only).
- Replace YOURPROFILE and YOURPAGE in the Instagram and LinkedIn links.
- Confirm organiser details, categories, eligibility, selection process, date and venue before announcing them.
- The website intentionally describes the awards as proposed and the event details as unannounced.

IMAGES
The provided logo is local. The hero artwork is CSS-built so the main design remains crisp and does not depend on external stock-photo services. Google Fonts are loaded externally; system fallbacks are included.
